# scry_olap

The `olap` kind for [Scry](https://github.com/joetjen/scry)
(lang_spec.md §2/§7).

Source: <https://github.com/joetjen/scry_olap>. Specs live in the
separate [`scry`](https://github.com/joetjen/scry) repository.
Implementation has not started yet on this branch.

## Installation

```elixir
def deps do
  [
    {:scry_olap, "~> 0.1"}
  ]
end
```
